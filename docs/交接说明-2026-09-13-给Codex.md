## 三、⚠️ VLM 6 轮 → 3 轮（改动最大，重点看）

### 为什么要改

同一段视频被完整传了 **6 遍**（每轮都重传整段），token 全花在这上面。实测 39 秒视频 6 轮 = 325k token。
同时产品方向改了：不再数次数，所以原来「传球 / 射门 / 防守」三个统计轮**整个删掉**。

### 新的 3 轮（`roundDefs`，`index.js:1117`）

| # | key | 输出结构 |
|---|---|---|
| 1 | `team` | `score` + `headline` + `highlights[{title,detail,time_hint}]` + `weaknesses[同结构]` + **`moments[]`** + `next_focus` |
| 2 | `players` | `players[{number, role, **strength**, **weakness**, notes[], tags[], is_mvp}]` |
| 3 | `technique` | `techniques[]` + `coaching_summary`（这轮没动） |

**关键变化**：

- `moments[]` 是 **3~6 个「值得回看的片段」**（进球、单刀、关键抢断、致命失误），**不是**原来的全量事件流水账。带 `time_seconds` 供前端做跳转回看。
- 球员多了 **`strength` / `weakness`** 两个字段（最大亮点 / 最大不足）。
- 原来 `summary.rounds` 里的 `passes` / `shots` / `defense` **三个 key 已不存在**，如果你手上有依赖它们的旧 JSON，注意区分。
- 去掉了「本场共识别到 N 个事件」的话术兜底 → 字段留 `null`，由前端走诚实空态。

### 好消息：前端类型基本不用改

`web/src/lib/instantAnalysis.ts` 里这些字段**早就支持**：

```
summary.highlight / weakness / recommendation / focus
players[].insights / techniques[] / tags / isMvp
```

而 `stats`（次数类）本来就只是可选字段，现在后端基本不再填它。
所以你要展示「亮点 / 不足 / 球员点评」，直接用现有类型即可。

`haoqiu-vlm/index.js` 里除了一个写死的记录字段 `analysis_mode: "multi_round_video"`（第 1066 行），**没有任何模式分支**。

**⇒ 三个模式共用同一套 prompt。** 这次 3 轮合并同时作用到了团队模式和个人模式。

用户当前的安排是：**个人模式先不测试**，等你后面要为它单独设计提示词时，再在后端加 `mode` 分支隔离。

如果你要改 prompt，记住：**改了就三个模式一起变**，除非先加分支。
