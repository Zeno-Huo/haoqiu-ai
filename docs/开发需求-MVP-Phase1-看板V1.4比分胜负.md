# 好球Ai · 数据看板 V1.4：比分 + 球队评分 + 胜负总结 + 卡片双列

> 在 V1.3 炫酷看板基础上增加：比分、球队整体评分、按胜负生成总结、球员卡片双列布局。

## 一、数据模型（types.ts）

- Match 增加 `myScore: number`（我方进球）、`oppScore: number`（对方进球）。

## 二、创建比赛（MatchNew.tsx）

- 比赛信息步骤加「比分」输入：我方进球 + 对方进球两个数字框，默认 0 : 0。

## 三、看板（MatchReport.tsx）

1. **顶部比分**：大字展示「我方 X : Y 对方」+ 胜负标签（胜 / 负 / 平），有醒目视觉。
2. **球队整体评分**：大字展示（1-10，保留 1 位小数，基于全队球员均分），视觉醒目。
3. **比赛总结模块**（在球员卡片前）：
   - **赢**（myScore > oppScore）：总结「最大亮点」+「不足」。
   - **输**（myScore < oppScore）：总结「最大可提升点」。
   - **平**：按「亮点 + 不足」处理。
4. **球员卡片双列**：桌面/平板 2 列网格（`sm:grid-cols-2`），移动端仍 1 列。hero 大数字随列宽自适应（clamp 已支持，必要时下调上限）。

## 四、引擎（engine.ts）

新增 `buildMatchSummary(match, analyses)`，基于客观数据 + 胜负推导（不写空话，每句可追溯到数据）：

- 全队汇总：总失误、传球成功率、射门/射正、拦截+抢断等。
- **最大亮点**（赢/平时用）：全队最突出的正向数据项，如「射门 N 次射正 M 次，门前效率高」「传球成功率 X%，串联流畅」「拦截+抢断 N 次，防守强硬」。
- **不足 / 最大可提升点**（输时强调为可提升点）：全队最弱短板，如「全队失误 N 次，控球处理需加强」「传球成功率仅 X%，配合是短板」「射正率低，门前把握需提升」。
- 返回结构化对象：`{ outcome: 'win'|'loss'|'draw', headline, points: string[] }` 或类似，前端渲染。

## 五、验收

- 建比赛可录比分；看板有比分、球队整体评分、胜负总结；卡片双列；`npm run build` 通过。
