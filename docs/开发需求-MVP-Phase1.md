## 1. 项目定位

**好球Ai** —— AI 足球多人比赛个人表现分析助手。

普通足球爱好者用一台手机录一场业余比赛（如 7v7 擂台赛），上传后 AI 自动识别关键足球事件，为每名球员生成个人技术复盘报告。

核心 slogan：**一台手机、一场比赛，每个人都有自己的复盘报告。**

产品不是职业战术分析，而是「让普通球员赛后快速知道：自己哪里踢得好、哪里要提升」。

## 2. 技术方案（MVP 决策）

- **前端**：Vite + React 18 + TypeScript + Tailwind CSS
  - 说明：PRD 建议 Next.js，但 MVP 目标是「快速可演示的完整用户流程」，先用 Vite 单页应用落地，后续可平滑迁移到 Next.js（SSR/API Routes）。
- **路由**：react-router-dom（HashRouter，保证单静态文件可部署可预览）
- **持久化**：localStorage（比赛记录、球员名单、分析报告），刷新不丢
- **AI 分析**：MVP 用**本地模拟分析引擎**生成「真实感、确定性」的 mock 数据，不接真实视频模型。
  - 真实视觉管线（YOLO / ByteTrack / MediaPipe / 视觉大模型 / LLM 报告）在后续阶段接入，代码里预留分析引擎接口（`analyzeMatch()`），便于替换。
- **图表**：轻量自绘 SVG（雷达图 + 条形图）优先；也可用 Recharts。

## 3. 功能范围（阶段一，全部要落地）

1. **首页** `/`：品牌「好球Ai」、slogan、三步说明（录制 → 上传 → 复盘）、「创建比赛」CTA
2. **创建比赛** `/match/new`：比赛名称、日期、比赛类型（5v5 / 7v7 / 11v11）、红队名、蓝队名
3. **上传视频**：拖拽/点击选择，校验 MP4/MOV、≤15 分钟，附录制要求提示（横屏、720P+、跟球）
4. **球员名单**：红队 / 蓝队分别录入「号码 + 姓名」；提供「一键生成示例名单」按钮便于演示
5. **AI 分析进度**：分阶段动画——上传 → 切片 → 人物识别 → 事件发现 → 动作分析 → 生成报告
6. **比赛报告** `/match/:id`：比赛总结、球员评分榜（按综合分排序）、精彩片段列表
7. **球员报告** `/match/:id/player/:pid`：综合评分 0–100、5 维能力雷达图、本场优势、主要问题、下一场建议、个人事件时间轴

## 4. 评分模型（每名球员）

综合评分 0–100，五个维度各 0–100：

1. 处理球能力：第一脚处理、停球质量、出球速度
2. 控球能力：带球稳定、被逼抢处理、身体保护
3. 传球能力：出球选择、时机判断、配合意识
4. 防守能力：防守动作、压迫选择、防守积极性
5. 比赛意识：提前观察、快速决策、无球移动


## 6. AI 报告文案示例（模拟引擎要能生成类似结构）

```
张三 · 综合评分 82
本场优势：
1. 接球后第一脚处理较积极
2. 面对压力敢于向前推进
主要问题：
1. 背身接球时身体没有打开
2. 传球后移动不足
下一场建议：训练接球前观察，尝试第一脚向前处理
```
