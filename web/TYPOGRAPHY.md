# 全局文字层级

规范入口：src/typography.css；由 main.tsx 最后加载。适用首页、上传、加载、球队报告及个人报告。

|用途|字号|字重|行高|
|---|---|---|---|
|综合评分|72–96px 自适应|700|1|
|首页主标题|40–64px 自适应|700|1.12|
|首页模式标题 / 球员评分|28px|600|1.3 / 1.2|
|上传入口标题|24px|600|1.4|
|页面标题 / 加载状态|20px|600|1.3–1.4|
|AI 分析总结|18px|500|1.6|
|模块标题 / 主按钮|16px|600|1.4|
|球员角色、亮点等子标题|14px|500|1.5|
|分析正文|14px|400|1.75|
|辅助说明、标签、状态步骤|12px|400|1.5|

原则：仅使用 400、500、600、700 四档字重。正文不整段加粗；中文正文不增加字间距。数字使用等宽数字，综合评分允许少量负字间距。正文不可为塞进一行而缩小，允许自然换行。可展开内容继承正文规格。颜色继续使用首页品牌变量，不以亮度代替文字层级。

雷达 SVG 的字号以 viewBox 单位定义，随图表等比例缩放，不能直接当成页面 px 数值；其字重仍遵守 400/600。大分数、首页标题是明确的展示级例外，普通业务组件须使用共享 type/weight 变量。

后续改动优先调整本规范的变量或语义选择器，不再在旧样式末尾叠加临时字号。
